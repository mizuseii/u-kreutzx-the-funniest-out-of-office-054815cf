# The Funniest Out-of-Office — "The Inbox With Boundaries"

> I'm out of office. My inbox learned boundaries faster than I did, so it will reply shortly — or possibly never, and honestly, good for it.

One-line out-of-office auto-reply for make.fun's "The Funniest Out-of-Office" bounty: the inbox finally learned to say no, and it is thriving without me.

## Run it

```sh
python3 main.py
```

This writes the single-line reply to `/output/entry.txt` (138 characters, no trailing newline).

Deterministic: no network, no randomness — the same bytes on every run.
